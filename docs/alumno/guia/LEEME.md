# Guia para alumnos y familias

Regenerar capturas y PDF (Docker levantado, BD jp_prodlike, Chrome, Pillow, PyMuPDF):

    python -I -X utf8 docs/alumno/guia/generar_guia.py docs/alumno/guia <carpeta_temporal>

Las capturas usan la alumna ficticia alumno.1096@prodlike.local. El PDF se publica a mano en
Documentacion > carpeta publica "Guias para alumnos" (en cada entorno: local, PPR y prod).
